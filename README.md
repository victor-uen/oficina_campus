# Oficina Campus

Projeto de Requisitos de Software e FCCPD.

Equipe: Artur Antunes, Luca, Ricardo, Victor e João Cláudio.

Estrutura Maven baseada no exemplo do professor: https://github.com/profsauloaraujo/sgb-2025-01

Esta etapa contém o pai Maven e as classes de domínio compartilhadas, incluindo
as referências que ligam uma ficha a uma ou a várias oficinas.
Para compilar e testar: `mvn verify` com JDK 17+ e Maven 3.6.3+.
